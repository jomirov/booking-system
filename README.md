## Жоба мақсаты
Іс-шаралар негізінде билет брондау жүйесін құру. Оның ішінде:
- Сервер API-эндпоинттерін,
- Аутентификация жүйесін,
- Фондық бақылау жүйесін,
- UI құру қарастырылады.
## Жобаны іске қосу
Жалпы жоба Docker бағдарламасы көмегімен құрылатын арнайы виртуалды ортада (контейнерде) жұмыс істейді. Docker қолдауымен жобаға қажетті технологиялар, оның ішінде:
- Python - FastAPI фреймворгі арқылы Backend әзірлеуде қолданылатын бағдарламалау тілі;
- PostgreSQL - деректер базасын басқару жүйесі;
- Redis - фондық механизмдерді жүзеге асыру үшін қолданылатын технология;
- Node - UI/UX пен жалпы Frontend бөлімін React жүйесі арқылы әзірлеуде қолданылатын орта автоматты түрде жүктеліп, іске қосылады.
### Backend
Docker Engine жүктеп, іске қосу және backend папкасында контейнерді көтеру (bash):
```bash
cd backend
docker compose up
```

### Frontend
frontend папкасында орналасып, контейнерді көтеру (bash):
```bash
cd frontend/vite-project
docker compose up
```
